# 3.6.3 · Table Design — Users, Patients, PatientStaff

The keys and field constraints of each table are given below. ID fields are generated by the system; PatientStaff has a composite key made of two foreign keys. These three tables form the identity and access core.

## Users · `users` (6 fields)

Staff accounts and the role/active information used for access.

**Table 4. Users fields**

| Field | Data type | Key / constraint |
|---|---|---|
| `user_id` | BIGINT identity | PK; automatic |
| `username` | VARCHAR(50) | UQ; 3–50 lowercase letters, digits or underscore |
| `full_name` | VARCHAR(100) | Required; cannot be blank |
| `password_hash` | TEXT | Required; secure hash output |
| `role` | VARCHAR(10) | admin / doctor / nurse |
| `is_active` | BOOLEAN | Required; default true |

## Patients · `patients` (4 fields)

Basic patient information and the unique record number used in the department.

**Table 5. Patients fields**

| Field | Data type | Key / constraint |
|---|---|---|
| `patient_id` | BIGINT identity | PK; automatic |
| `patient_no` | VARCHAR(20) | UQ; required |
| `full_name` | VARCHAR(100) | Required; cannot be blank |
| `birth_date` | DATE | Required; cannot be in the future (service) |

## PatientStaff · `patient_staff` (2 fields)

Current patient–staff assignments. One row links one patient with one staff member.

**Table 6. PatientStaff fields**

| Field | Data type | Key / constraint |
|---|---|---|
| `patient_id` | BIGINT | Part of PK; FK Patients; required |
| `user_id` | BIGINT | Part of PK; FK Users; required |

## Users · `users` (6 alan)

Personel hesapları ve erişimde kullanılan rol/aktiflik bilgileri.

**Tablo 4. Users alanları**

| Alan | Veri tipi | Anahtar / kısıt |
|---|---|---|
| `user_id` | BIGINT identity | PK; otomatik |
| `username` | VARCHAR(50) | UQ; 3–50 küçük harf, rakam veya alt çizgi |
| `full_name` | VARCHAR(100) | Zorunlu; boşluk olamaz |
| `password_hash` | TEXT | Zorunlu; güvenli hash çıktısı |
| `role` | VARCHAR(10) | admin / doctor / nurse |
| `is_active` | BOOLEAN | Zorunlu; varsayılan true |

## Patients · `patients` (4 alan)

Hastanın temel bilgileri ve bölüm içinde kullanılan benzersiz kayıt numarası.

**Tablo 5. Patients alanları**

| Alan | Veri tipi | Anahtar / kısıt |
|---|---|---|
| `patient_id` | BIGINT identity | PK; otomatik |
| `patient_no` | VARCHAR(20) | UQ; zorunlu |

## PatientStaff · `patient_staff` (2 alan)

Güncel hasta–personel atamaları. Bir satır bir hasta ile bir personeli bağlar.

**Tablo 6. PatientStaff alanları**
