# Abstract

The Patient Monitoring Profile System is designed for a single hospital department to link patient records, timestamped health measurements, and staff task messages. Its relational model consists of six tables covering users, patients, current assignments, measurement types, measurements, and messages. Clinical access requires both an eligible user role and a current patient assignment. Each message has one sender, one recipient, and one completion result. This Phase 1 work defines the scenario, business rules, ER and UML models, table specifications, relational algebra queries, index design, transaction workflows, and evaluation plan. No implementation results or measured performance improvements are claimed.
